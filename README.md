# Deepam Light Controller

Deepam Light Controller is a autonomous controller for solar-powered light for temple use. It drives the battery powered LED lamp, detecting dusk and dawn from a light sensor and controlling LED brightness using PWM on a dusk-relative schedule.

> **Status:** In development

## Features

- Detects the dusk and dawn using an LDR, with solar panel voltage as second reference
- Dims the LED lamp through on a dusk-relative schedule, with no real time clock is needed.
- Learns each night length to estimate midnight, adapting automatically for seasons
- Dims LED lamp using PWM signal generated by MOSFET
- Rejects false switching by shadows or clouds
- Detects failed sensor and fall backs to the other one
- Compile time lamp profiles for different wattages
- Register level drivers (no-HAL) for FreeRTOS based scheduling

## Hardware

| Component | Purpose |
|---|---|
| STM32F103C8T6 (Cortex-M3, 72 MHz, 64 KB flash, 20 KB RAM) | Main controller (MCU) |
| 8 MHZ crystal | External clock source (HSE) PLL |
| LDR + resistor dividor | Light sensor |
| IRLZ44N | Mosfet to control switching |
| Buck Converter | Power source for MCU |
| Solar voltage divider | measure solar voltage |
| Solar charger controller | Controls the battery charging from solar panel |
| Battery and Solar panel | Power source and Energy source |
| 12V DC lamp | The light being controlled |

### Pin Map

| Signal | Pin | Peripheral |
|---|---|---|
| LDR input | PA0 | ADC1 channel 0 | 
| Status LED | PC13 | GPIO output (active low) |
| Lamp PWM output | PA1 | TIM channel 2 |
| Solar panel voltage | PA2 | ADC1 channel 4 |
